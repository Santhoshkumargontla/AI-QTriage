# RISK LABEL GENERATION SPECIFICATION

- **LOW (0)**: Severity score < 0.32 (Stable vitals, low pain <= 3, peak G < 2.0g)
- **MODERATE (1)**: Severity score 0.32 - 0.58 (Moderate pain 4-6, G-force 2.0g-6.0g, cut/bruise presence)
- **HIGH (2)**: Severity score >= 0.58 (Severe pain >= 7, G-force >= 6.0g, active bleeding, movement limitation)
