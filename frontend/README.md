# AI-QTriage frontend

Next.js 16 UI for the research prototype. Not a clinical product.

```bash
npm install
npm run dev
```

API base: `NEXT_PUBLIC_API_URL` (default `http://localhost:8000`). See the repository root `README.md` for models, simulation vs real data, and Twilio/SOS limits.

```bash
npm run lint
npm run build
```
