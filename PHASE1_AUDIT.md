## 1. Executive Summary

This forensic audit investigates the empirical reality of the AI-QTriage research codebase, its model checkpoints, evaluation artifacts, dataset manifests, and published manuscript text. The objective is to establish an unassailable, evidence-backed foundation before modifying datasets, re-running evaluations, retraining models, or revising the manuscript.

### Primary Audit Verdict
- **Code and Model Artifacts Are Real and Functioning:** All 6 model components (YOLO11, EfficientNetV2-S, ResNet34-U-Net, Sensor Motion Classifier, Multimodal XGBoost, and 4-Qubit VQC) have authentic checkpoints with verified SHA-256 hashes that execute inference cleanly.
- **Reported Numbers Originate in Real Evaluation Runs:** None of the numerical results in Table 1 or Section VI were arbitrarily manufactured; they were extracted from real JSON evaluation artifacts (`data/results/canonical_held_out_evaluation.json`, `ml/models/model_registry.json`, `ml/models/sensor_metadata.json`, and `ml/models/vision/unet_metadata.json`).
- **Major Manuscript Inconsistencies Discovered:**
  1. **YOLO11:** Section 3.3 reports $mAP@50 = 83.58\%$ and $mAP@50\text{--}95 = 70.80\%$ (derived from a synthetic drawing test set of 19 images with 0 wound labels), while the Abstract, Section VI, and Reviewer 1 report $mAP@50 = 36.47\%$ and $mAP@50\text{--}95 = 18.44\%$ (derived from real photographic wound datasets).
  2. **Sensor Classifier:** Section 3.7 reports $\text{Accuracy} = 28/36 = 77.78\%$ (derived from an obsolete synthetic 200-series simulation), while Table 1, Section VI, and Reviewer 2 report $\text{Accuracy} = 1,183/1,228 = 96.34\%$ (derived from real SisFall/UCI HAR 50Hz sliding windows).
  3. **U-Net Segmentation:** Section 3.5 leaves the test Dice score blank (`"Current reported test Dice score: "`), while Section VI reports $64.18\%$. The probability mask binarization threshold ($\tau = 0.50$) was omitted from the manuscript.
  4. **EfficientNetV2:** The paper reports Macro-F1 = $93.75\%$ (an intermediate uncalibrated validation run), whereas the canonical test evaluation on 473 held-out photographic images achieved Macro-F1 = $94.34\%$ (Accuracy $96.62\%$).
  5. **Train/Test Leakage in Synthetic Fusion:** Exact row hashing revealed that Index 21 of the synthetic test set is identical to Index 84 of the training set due to discrete modality dropout zeroing out common dimensions.
  6. **Multimodal Ground Truth Circularity:** The 200-record multimodal tabular dataset has 0 real patient records; ground truth labels (`LOW`, `MODERATE`, `HIGH`) are generated by deterministic mathematical inequalities (`ml/fusion/rules_engine.py` and `train_xgboost.py`), which XGBoost approximates.

## 3. Detailed Root-Cause Analysis by Task

### Task 1 — YOLO11 Evaluation Conflicts
- **Problem:** Section 3.3 asserts $mAP@50 = 83.58\%$ and $mAP@50\text{--}95 = 70.80\%$. In contrast, Section VI, Abstract, and Reviewer 1 report $36.47\%$ and $18.44\%$.
- **Root Cause:** 
  - $83.58\%$ was evaluated on `data/datasets/yolo_retrain_v2`, consisting of 126 synthetic digitized drawing sketches ($87$ train, $20$ val, $19$ test). The test set had only 19 images ($8$ cut, $10$ bruise), and the training set contained **0 wound bounding boxes**.
  - $36.47\%$ was evaluated on real photographic trauma datasets (`yolo_expanded_v1` / `yolo_candidate_training`, 123 images partitioned $83$ train, $17$ val, $23$ test; and expanded sets up to 1,790 images).
- **Evidence:** `ml/models/yolo_threshold_eval/THRESHOLD_SWEEP_REPORT.json` and `scratch/yolo_baseline_vs_candidate.json`.
- **Resolution Strategy:** Standardize on real photographic performance ($36.47\% / 18.44\%$) as the primary reported result in all sections. Clarify that 83.58% was an initial synthetic-drawing baseline that does not translate to clinical photographs.

### Task 2 — Sensor Model Metric Conflicts
- **Problem:** Section 3.7 reports $28/36 = 77.78\%$ accuracy, while Section VI and Table 1 report $1,183/1,228 = 96.34\%$.
- **Root Cause:**
  - $28/36$ was the held-out test split of an obsolete synthetic simulation (`synthetic_sensor_v1.2.0`, 200 total series split $140 / 24 / 36$).
  - $1,183/1,228$ is the authentic test performance on $N = 1,228$ segmented 2.5-second sliding windows derived from SisFall (4,505 windows) and UCI HAR (2,000 windows).
- **Evidence:** `ml/models/sensor_metadata.json` lines 11–50: $4,247$ train, $1,030$ val, $1,228$ test windows. $\text{Accuracy} = 1,183 / 1,228 = 0.963355$.
- **Class Imbalance Finding (Addressing Reviewer 2 Comment 4):**
  - Normal Activity: $n=720 \implies \text{Precision}=98.89\%, \text{Recall}=98.75\%, \text{F1}=98.82\%$
  - Fall: $n=448 \implies \text{Precision}=94.89\%, \text{Recall}=95.31\%, \text{F1}=95.10\%$
  - Impact: $n=60 \implies \text{Precision}=76.27\%, \text{Recall}=75.00\%, \text{F1}=75.63\%$
- **Resolution Strategy:** Purge the obsolete 28/36 metric. Report 96.34% ($1,183/1,228$) across all sections and provide the full per-class classification report highlighting the minority Impact class ($75.0\%$ recall).

### Task 3 — ResNet34-U-Net Segmentation Verification
- **Problem:** Section 3.5 leaves the test Dice field blank (`"Current reported test Dice score: "`), and Reviewer 2 flags that the binarization threshold is missing.
- **Root Cause:** Editorial omission during manuscript drafting. The evaluation had already completed and was saved in `ml/models/vision/unet_metadata.json`.
- **Evidence:** `unet_metadata.json` lines 21–31: $N = 69$ held-out photographic pairs, $\text{Mean Dice} = 0.641808$ (64.18%), $\text{Mean IoU} = 0.517783$ (51.78%), $\text{Threshold } \tau = 0.50$.
- **Resolution Strategy:** Populate Section 3.5 with $64.18\%$ Dice, $51.78\%$ IoU, and explicitly define the mask binarization threshold as $\tau = 0.50$.

### Task 4 — EfficientNetV2-S Classification Verification
- **Problem:** The manuscript reports Macro-F1 = 93.75%, while `model_registry.json` reports 94.34%.
- **Root Cause:** 93.75% was an uncalibrated validation epoch checkpoint. The canonical test evaluation on $N = 473$ held-out Kaggle wound photos achieved:
  - Accuracy: $96.62\%$
  - Macro-F1: $94.34\%$
  - Macro-Precision: $94.26\%$
  - Macro-Recall: $95.01\%$
- **Evidence:** `ml/models/model_registry.json` lines 257–313.
- **Resolution Strategy:** Update the paper to state Macro-F1 = $94.34\%$ on $N = 473$ held-out photographic test images.

### Task 5 — Multimodal Train/Test Hash Overlap
- **Problem:** Data leakage audit flagged an exact feature-vector match between training row 84 and test row 21.
- **Root Cause:** In [`ml/training/train_xgboost.py`](file:///c:/Users/santh/Capstone%20Project%20Code/ml/training/train_xgboost.py#L46-L100), modality dropout randomly zeroes out entire modality subsets (30% of samples). When both vision and sensor modalities are dropped, only questionnaire features remain. In small discrete feature combinations, two random draws produced identical survey responses with zeroed vision/sensor vectors.
- **Evidence:** Re-running vector hashing on `generate_multimodal_dataset(200, seed=42)` confirmed:
  $$\text{hash}(X_{\text{train}}[84]) == \text{hash}(X_{\text{test}}[21])$$
- **Resolution Strategy:** Disclose this exact 1-sample overlap ($3.33\%$ of the 30-sample test set) in the audit report and dataset report.

### Task 6 — Multimodal Ground Truth & Label Heuristics
- **Problem:** Reviewer 2 Comment 2 notes that the exact rules assigning `LOW`, `MODERATE`, and `HIGH` triage labels are not specified.
- **Root Cause:** Labels in `train_xgboost.py` are generated using a deterministic linear severity index:
  $$\text{Severity} = 0.4 \times \text{pain} + 0.3 \times \text{peak\_g} + 0.3 \times \text{affected\_area}$$
  - $\text{Severity} < 0.32 \implies \text{LOW}$
  - $0.32 \le \text{Severity} < 0.58 \implies \text{MODERATE}$
  - $\text{Severity} \ge 0.58 \implies \text{HIGH}$
  In runtime inference, [`ml/fusion/rules_engine.py`](file:///c:/Users/santh/Capstone%20Project%20Code/ml/fusion/rules_engine.py#L28-L58) applies clinical heuristic bounds (e.g., crack/pop + immobility $\implies$ HIGH).
- **Resolution Strategy:** Formally document these exact mathematical label criteria in Section 3.1 and Section 3.9 of the manuscript, explicitly framing them as "Rule-Derived Synthetic Research Categories".

### Task 7 — Modality Ablation Study
- **Problem:** Reviewer 1 Comment 4 notes that the paper does not demonstrate individual modality contributions through an ablation study (`"ablation_study": []` in JSON).
- **Root Cause:** Modality dropout was trained into the model, but formal ablation evaluation was never serialized into the paper.
- **Resolution Strategy:** Execute a clean 7-configuration ablation study on the held-out test split (Vision Only, Survey Only, Sensor Only, Vision+Survey, Vision+Sensor, Survey+Sensor, All Modalities) and insert the resulting table into Section VI.

### Task 8 — Quantum VQC Positioning
- **Problem:** Reviewer 1 Comment 6 notes that the quantum classifier achieves only 53.33% accuracy, significantly below classical XGBoost.
- **Root Cause:** The 4-qubit VQC runs via AngleEmbedding and StronglyEntanglingLayers on PennyLane's `default.qubit` simulator. On 3 classes, 53.33% ($16/30$) barely exceeds 33.3% random baseline, yielding $\text{MCC} = 0.095978$.
- **Resolution Strategy:** Clarify that VQC is an exploratory proof-of-concept for quantum circuit integration; explicitly state that **no quantum advantage is claimed** and that classical XGBoost is the authoritative decision model.
